# 海冰预测检验 API 规格说明

本文档定义了海冰板块预测检验页面所需的三个后端 API 接口，请后端同学根据此规范进行开发。

---

## 1. SIC日预测误差

**接口信息**

- 路径：`/seaice/error`
- 方法：`GET`
- 功能：获取指定起报年份和月份的 SIC 日预测误差数据（BACC 和 RMSE），用于绘制折线图。

**请求参数**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
| ------ | ---- | ---- | ---- | ---- |
| `year` | int | 是 | 起报年份 | `2023` |
| `month` | int | 是 | 起报月份（1~12） | `1` |

**响应格式**

```json
{
  "{year}_BACC": [0.72, 0.68, ...],        // 模型预测的 BACC 值，单位为比例（前端 ×100 显示为 %）
  "{year}_per_BACC": [0.60, 0.55, ...],    // Persistence 基准的 BACC 值
  "{year}_RMSE": [0.12, 0.14, ...],        // 模型预测的 RMSE 值，单位为比例
  "{year}_per_RMSE": [0.18, 0.20, ...]     // Persistence 基准的 RMSE 值
}
```

- 所有字段均为**数值数组**，长度相同（一般为样本天数，建议 ≥ 7）。
- 字段名中的 `{year}` 需替换为请求参数中的实际年份。
- 数组中每个值对应一个样本（如第1天、第2天……）。

**示例**
请求：`GET /seaice/error?year=2023&month=1`
响应：
[json]
{
  "2023_BACC": [0.72, 0.68, 0.74, 0.80, 0.77, 0.82, 0.79],
  "2023_per_BACC": [0.60, 0.55, 0.58, 0.62, 0.59, 0.63, 0.61],
  "2023_RMSE": [0.12, 0.14, 0.13, 0.11, 0.15, 0.10, 0.12],
  "2023_per_RMSE": [0.18, 0.20, 0.19, 0.17, 0.21, 0.16, 0.18]
}
[/json]

## 2. SIC误差统计（箱型图）

**接口信息**

- 路径：`/seaice/errorBox`
- 方法：`GET`
- 功能：获取指定起报年份和月份的 SIC 误差统计数据，用于绘制箱型图。

**请求参数**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
| ------ | ---- | ---- | ---- | ---- |
| `year` | int | 是 | 起报年份 | `2022` |
| `month` | int | 是 | 起报月份（1~12） | `4` |

**响应格式**

```json
{
  "withoutDA_withoutBC": [ [0.22, 0.25, ...], [0.23, 0.26, ...], ... ],
  "withoutDA_withBC_RMSE": [ [0.15, 0.17, ...], [0.16, 0.18, ...], ... ],
  "withDA_withoutBC_RMSE": [ [0.13, 0.14, ...], [0.14, 0.15, ...], ... ],
  "MITgcm(with DA)withBC_RMSE": [ [0.11, 0.12, ...], [0.12, 0.13, ...], ... ]
}
```

- 每个字段是一个**二维数组**，外层代表不同样本（例如不同起报日），内层代表**提前1~N天**的 RMSE 值。
- 内层数组长度通常为 7（提前1~7天），但可以是其他固定长度。
- RMSE 值为比例，前端会乘以100显示为百分比。

**示例**
请求：`GET /seaice/errorBox?year=2022&month=4`
响应：

```json
{
  "withoutDA_withoutBC": [
    [0.22, 0.25, 0.21, 0.27, 0.20, 0.23, 0.24],
    [0.23, 0.26, 0.22, 0.28, 0.21, 0.24, 0.25],
    [0.20, 0.22, 0.19, 0.25, 0.18, 0.21, 0.22]
  ],
  "withoutDA_withBC_RMSE": [
    [0.15, 0.17, 0.14, 0.18, 0.13, 0.16, 0.15],
    [0.16, 0.18, 0.15, 0.19, 0.14, 0.17, 0.16],
    [0.14, 0.16, 0.13, 0.17, 0.12, 0.15, 0.14]
  ],
  "withDA_withoutBC_RMSE": [
    [0.13, 0.14, 0.12, 0.15, 0.11, 0.13, 0.14],
    [0.14, 0.15, 0.13, 0.16, 0.12, 0.14, 0.15],
    [0.12, 0.13, 0.11, 0.14, 0.10, 0.12, 0.13]
  ],
  "MITgcm(with DA)withBC_RMSE": [
    [0.11, 0.12, 0.10, 0.13, 0.09, 0.11, 0.12],
    [0.12, 0.13, 0.11, 0.14, 0.10, 0.12, 0.13],
    [0.10, 0.11, 0.09, 0.12, 0.08, 0.10, 0.11]
  ]
}
```

## 3. SIE误差分析

**接口信息**

- 路径：`/seaice/predictionExamination/errorAnalysis`
- 方法：`GET`
- 功能：获取指定年份的 SIE 误差分析数据，用于绘制4个子图（RMSD、偏差/方差、相关系数、标准差）。

**请求参数**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
| ------ | ---- | ---- | ---- | ---- |
| `year` | int | 是 | 分析年份 | `2022` |

**响应格式**

```json
{
  "RMSD": [0.12, 0.15, 0.18, ...],       // 长度固定为12，提前1~12个月的 RMSD（百万 km²）
  "BAIS": [0.02, 0.03, 0.05, ...],       // 偏差平方（百万 km²）²
  "VAR": [0.10, 0.12, 0.13, ...],        // 方差（百万 km²）²
  "CORRELATION": [0.98, 0.97, 0.96, ...], // 相关系数（0~1）
  "OBS_STD": [2.1, 2.0, 1.9, ...],       // 观测标准差（百万 km²）
  "PRE_STD": [2.0, 1.9, 1.8, ...]        // 预报标准差（百万 km²）
}
```

- 所有字段均为**长度为 12 的数组**，分别对应提前 1~12 个月。
- 数值单位：RMSD、OBS_STD、PRE_STD 单位为百万 km²；BAIS 和 VAR 单位为 (百万 km²)²；CORRELATION 无量纲。

**示例**
请求：`GET /seaice/predictionExamination/errorAnalysis?year=2022`
响应：
[json]
{
  "RMSD": [0.12, 0.15, 0.18, 0.22, 0.25, 0.28, 0.30, 0.33, 0.35, 0.38, 0.40, 0.42],
  "BAIS": [0.02, 0.03, 0.05, 0.08, 0.10, 0.12, 0.15, 0.18, 0.20, 0.22, 0.25, 0.28],
  "VAR": [0.10, 0.12, 0.13, 0.14, 0.15, 0.16, 0.15, 0.15, 0.15, 0.16, 0.15, 0.14],
  "CORRELATION": [0.98, 0.97, 0.96, 0.95, 0.94, 0.93, 0.92, 0.91, 0.90, 0.89, 0.88, 0.87],
  "OBS_STD": [2.1, 2.0, 1.9, 1.8, 1.7, 1.6, 1.5, 1.4, 1.3, 1.2, 1.1, 1.0],
  "PRE_STD": [2.0, 1.9, 1.8, 1.7, 1.6, 1.5, 1.4, 1.3, 1.2, 1.1, 1.0, 0.9]
}
[/json]

## 补充说明

- **数值格式**：所有数值请以**原始小数**返回（如 RMSE=0.12），前端会自动处理单位（如乘以100显示 %）。
- **数组长度**：
  - `/seaice/error` 的数组长度无硬性限制，建议 ≥ 7。
  - `/seaice/errorBox` 的内层数组长度建议为 7（提前1~7天），外层数组长度代表样本数，可灵活。
  - `/seaice/predictionExamination/errorAnalysis` 的所有字段**必须长度为 12**（对应提前1~12个月）。
- **跨域**：请确保后端已配置 CORS，允许前端域名访问。
- **错误处理**：若请求参数无效或无数据，建议返回 HTTP 400 并附带错误信息；若数据缺失，可返回空数组但需保证字段存在。

## 初始化接口（可选，用于前端日期选择器范围）

前端在页面加载时会调用以下三个初始化接口，用于限制日期选择器可选范围。若未实现，不影响图表渲染，但日期选择器可能无范围限制。

- `GET /seaice/initial/SICError` → 返回 `{ yearList: [年份], monthList: [月份] }`
- `GET /seaice/initial/SICErrorBox` → 同上
- `GET /seaice/initial/SIEErrorAnalysis` → 同上

如果实现了，请确保返回格式一致，以便前端正确解析。
